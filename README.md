# 日語階梯（N4 → N3 個人日文學習網站｜第一版）

繁體中文介面的個人日文學習網站，提供「今日學習 → 單字卡 → 文法筆記 → 練習與錯題本 → 學習紀錄與設定」完整學習流程。

> **重要聲明**
> - 本專案內含之 20 個單字、5 篇文法與 15 道選擇題皆為功能驗證用之自編示範教材，全數標示「**示範內容，待校對**」，**不宣稱已經人工校對**。
> - `N4`、`N3` 僅作為學習分類標示，並非官方完整題庫或詞表。
> - 學習紀錄僅保存於目前使用的瀏覽器 `localStorage`，不同裝置不會自動同步，清除網站資料可能失去紀錄，請定期使用「匯出 JSON 備份」。

---

## 一、本機啟動說明

本專案採用純靜態前端（HTML / CSS / 原生 ES Modules）與零外部相依套件的 Node.js 本機伺服器，不需執行 `npm install` 或建置步驟。

### 系統需求
- Node.js（建議 v18 以上；開發環境已於 v26.13.1 驗證）

### 啟動步驟
1. 在專案根目錄開啟終端機，執行：
   ```bash
   node server.mjs
   ```
2. 看到以下訊息後，於瀏覽器開啟 `http://127.0.0.1:4173`：
   ```text
   日語階梯本機伺服器已啟動：http://127.0.0.1:4173
   ```
3. 若需更換連接埠，可設定環境變數 `PORT`（例如 PowerShell：`$env:PORT=8080; node server.mjs`）。

### 部署至 GitHub Pages
本專案所有資源皆使用相對路徑（`./styles/main.css`、`./src/app.js`），推送至 GitHub 後可直接於 Repository 的 **Settings → Pages** 選擇分支根目錄（`/`）啟用 GitHub Pages，無需額外打包設定。

## 二、教材新增與替換方式

所有教材皆獨立存放於 `src/data/`，與程式邏輯及介面分離：

- 單字：`src/data/vocab.js`（匯出 `VOCAB_LIST`）
- 文法：`src/data/grammar.js`（匯出 `GRAMMAR_LIST`）
- 練習題：`src/data/quizzes.js`（匯出 `QUIZ_LIST`）
- 複習間隔設定：`src/config/studyConfig.js`（集中管理 `reviewIntervalsDays`：預設不熟 1 天、有點熟 3 天、熟悉 7 天）

### 新增教材注意事項
1. **唯一且穩定的 ID**：每筆資料的 `id`（如 `vocab_n4_001`、`gram_n3_001`、`quiz_001`）必須全站唯一且不可任意變更，否則會影響既有的本機學習紀錄對應。
2. **詮釋欄位**：建議保留 `source`（來源）、`contentVersion`（版本）與 `reviewStatus`（校對狀態）。
3. **練習題選項判定**：`quizzes.js` 透過 `correctOptionId` 對應 `options[].id` 判分，而非固定陣列索引，因此可安全打亂選項順序。新增題目時請確保只有唯一正解，若有語意模糊或多重合理答案疑義，請先列入待確認清單再上架。

## 三、已完成與未完成功能清單

### 已完成（第一版）
- **今日學習（`#today`）**：顯示今日待複習單字數、未讀文法數、錯題本數量與快速導引按鈕，首頁維持簡潔不塞圖表。
- **單字卡（`#vocab`）**：支援 N4／N3 分類、主題分組與學習狀態篩選；提供瀏覽器內建日語語音朗讀（`🔊 朗讀單字`、`🔊 朗讀例句`）；先顯示題面，點擊「顯示答案」後才展開讀音、中文、詞性與例句；翻面不自動標記熟悉，須由使用者選擇「不熟 / 有點熟 / 熟悉」並依集中設定計算下次複習日；無待複習卡片時顯示空白狀態。
- **文法筆記（`#grammar`）**：顯示意思、接續、使用情境、例句翻譯與注意事項，支援例句語音朗讀；「已閱讀」與「熟練度」分開記錄。
- **練習與錯題本（`#practice`）**：單選題支援選項打亂並依選項 ID 判分、題目語音朗讀；提交後顯示文字結果（`✓ 答對了！` / `✕ 答錯了`）與解析，並鎖定當題防止重複計分；錯題依題號去重、保存錯誤次數與最近錯選／作答時間，支援「只練錯題」且重新答對後仍保留歷史紀錄。
- **學習紀錄與設定（`#records`）**：提供學習統計、本機儲存風險提示、JSON 匯出、匯入前格式與版本驗證（失敗不覆蓋原資料）與二次確認機制，以及二次確認重設功能。

### 未完成／後續版本規劃
- 真人預錄音檔與假名／漢字切換顯示
- 多題型支援（如重組題、聽力題）
- 題庫與教材人工校對完成後更新 `reviewStatus`
- 跨裝置雲端同步（目前僅本機瀏覽器保存）

### 已執行測試
- **Node 單元測試**（`node --test tests/studyLogic.test.mjs`）：**6 / 6 通過**
  - 教材數量（20 單字 / 5 文法 / 15 題）、唯一 ID 與「示範內容，待校對」欄位檢查
  - 單字卡 1 / 3 / 7 天複習間隔計算與到期判斷
  - 文法「已閱讀」與「熟練度」獨立性檢查
